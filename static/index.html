Known limitations
  • Username and email work reasonably well. Name-only search is unreliable and is not offered as a primary input.
  • Instagram, Facebook, and other login-walled sites usually block unauthenticated scanners. A miss is not proof the account is absent.
  • Sherlock and Maigret can report false positives (soft 404s). Treat a single hit as weak evidence.
  • holehe infers registration from signup/recovery responses; it does not access accounts. Modules can break or rate-limit.
  • Have I Been Pwned email search needs a paid API key. Without HIBP_API_KEY you get a manual link only. Breach dumps are never downloaded.
  • Most Kali “OSINT” tools target domains and networks, not people. This app runs a small, structured set and degrades if a binary is missing.
  • The exposure score is a transparent teaching device, not a scientific risk rating.
  • Gemini, if configured, is instructed to summarize only the given facts. If the key is missing or the API returns 429, the rest of the report still works.
Educational use on localhost. Not legal advice. In India, the DPDP Act 2023 and the IT Act still apply to personal data even when it was found in public sources. Search only yourself, or a classmate who has consented. See the README for the ethics note and viva questions.
